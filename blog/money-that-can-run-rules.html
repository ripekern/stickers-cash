Money that can run rules

Bitcoin Cash is not just a payment rail. Every coin is locked by a small program. Programmability starts with that fact — and it changes what money can do.

Post 25 of 37 · 3 min read · Oct 22, 2026

Every Bitcoin Cash transaction already follows rules. When you pay someone, your wallet does not send a file or update an account. It creates a transaction that moves coins from one set of rules to another. The network checks those rules and either accepts the result or rejects it.

That is the foundation of programmability. BCH is not a payment system with a separate smart contract platform bolted on top. The payment layer is the rule layer. The question is how much logic the network will enforce, and how cleanly that logic can be written.

Coins carry their own rules

Think of each BCH coin as having a small rule book attached. Normally the rule is simple: "whoever holds the key can spend this." But you can write more interesting rules. You can say: "this can only be spent if two out of three people agree." Or "only after a certain date." Or "only if a specific token moves along with it." The rule travels with the coin wherever it goes.

This is the big idea. You do not need a separate platform or a middleman to enforce agreements. The money itself carries the agreement, and the network checks the rules before accepting the payment.

Simple rules, real results

Because the rules are small and live on the coins themselves, they are cheap to use. There is no giant shared computer that everyone has to pay to run. The fee is just the normal BCH fee — a fraction of a cent — and it is based on the size of the transaction, not on how many steps a computer had to take.

BCH focuses on money, assets, and settlement. That focus is the advantage: the rules stay small, the fees stay low, and you get exactly what you need for payments without the overhead of a giant computer platform.

The toolbox has been growing

For years, BCH could already handle things like shared approvals, timed releases, and simple conditions. Then the toolbox expanded quickly:

  • 2022: Coins that can inspect the transaction spending them — so a rule can check where the money is going.
  • 2023: Native tokens and NFTs added to the same chain.
  • 2025–2026: More expressive contracts — coins can follow more complex rules without needing a separate platform.

BCH does not need to be everything. It is becoming a better version of itself: money that can enforce useful rules, with the same cheap settlement and self-custody that made it interesting in the first place.

The rest of this chapter is about what those rules can actually do.
