NFTs with the receipt built in

A BCH NFT is not a link to a picture. It is a token with an on-chain commitment that contracts can read — a receipt, a ticket, or a piece of state.

Post 25 of 30 · 3 min read · Oct 22, 2026

The phrase “NFT” usually brings to mind a JPEG and a marketplace. On Bitcoin Cash, the technical object is more interesting: an indivisible token with a commitment, a short piece of data that the network can attest to and contracts can inspect.

What is inside a BCH NFT

A CashToken NFT has three properties: a category, a commitment, and a capability. The category identifies the token family. The commitment is the data payload. The capability controls whether the NFT can be changed or whether new NFTs can be minted.

There are three capabilities. A minting NFT can create more NFTs in the same category. A mutable NFT can update its commitment when spent. An immutable NFT cannot change. That gives issuers a way to model supply, state, and permanence without a separate contract database.

The 2026 upgrade raised the standard commitment limit from 40 bytes to 128 bytes and made bare pay-to-script outputs standard. That is enough for the important part: the claim. A hash, an identifier, a timestamp, a score, a ticket number, or a compact state record fits comfortably.

A receipt, not a picture

The useful question is not “what image is attached?” It is “what claim does this token enforce?” A ticket NFT can carry the event ID and seat. A membership NFT can carry a tier and expiry. A receipt NFT can carry an order hash. A game item can carry stats that a contract reads when the item is used.

Because the commitment is on-chain, a contract can require it. A gate contract can check that the NFT has the right category and commitment before releasing funds. A marketplace can verify that a ticket is authentic without asking a platform. The token is not just a collectible; it is a verifiable input to a rule.

Metadata lives at the edges

Large media and rich metadata live at the edges by design. The chain holds the token and the commitment; a metadata registry holds the presentation. Bitcoin Cash Metadata Registries (BCMR) provide a standard, authenticated way to publish names, descriptions, and icons. The result is a compact on-chain claim with rich presentation around it.

What NFTs unlock

NFTs are most useful when they are part of a contract, not an isolated collectible. A redeemable NFT can act as a receipt: return it to a contract and receive the underlying asset. A role NFT can act as an admin key: the contract checks for it before allowing a privileged spend. A state NFT can hold the latest commitment for a vault or a streaming payment.

That is the pattern to watch. The NFT is not the product. It is the proof that the product’s rule was followed. The product might be a ticket, a membership, a loan, a game, or a claim on a real-world asset.

Built for verifiable claims

A BCH NFT is a compact, verifiable token. It is designed for tickets, receipts, memberships, game items, and state that a contract can read. Large media stays off-chain, and the on-chain commitment proves what matters. That is the right division of labor for a payment network.

Used well, an NFT becomes more than a collectible: it is a claim that a contract can verify without a platform. A ticket, a receipt, or a membership becomes a real, enforceable digital object. The JPEG was never the point.
