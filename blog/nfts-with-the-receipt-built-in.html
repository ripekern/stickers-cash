NFTs with the receipt built in

A BCH NFT is not a link to a picture. It is a token with a small piece of data built in — a receipt, a ticket, or a checkable claim.

Post 27 of 37 · 3 min read · Oct 22, 2026

The phrase "NFT" usually brings to mind a JPEG and a marketplace. On Bitcoin Cash, the technical object is more interesting: a one-of-a-kind token with a small piece of data built in — data that the network can verify and that rules can check.

What is inside a BCH NFT

A BCH NFT has three parts: a family (which project or issuer it belongs to), a claim (a short piece of data the network can check), and a mode (whether it can be changed or whether more can be made).

There are three modes. A minting NFT can create more NFTs in the same family. A changeable NFT can update its claim when it is spent. A fixed NFT cannot change once it is created. That gives creators a way to control supply, update information, or lock something in permanently — all without a separate database.

The 2026 upgrade made the claim area bigger — enough for a hash, a timestamp, a score, a ticket number, or a small piece of information that matters.

A receipt, not a picture

The useful question is not "what image is attached?" It is "what does this token prove?" A ticket NFT can carry the event name and seat. A membership NFT can carry a level and expiry date. A receipt NFT can carry an order number. A game item can carry stats that a rule reads when the item is used.

Because the data is on the chain, a rule can check it. A gate rule can check that the NFT has the right family and data before releasing funds. A marketplace can check that a ticket is real without asking a platform. The token is not just a collectible; it is something a rule can actually check.

Details live outside the chain

Large files and rich details live outside the chain on purpose. The chain holds the token and the claim; a registry holds the presentation — names, descriptions, and icons. The result is a compact on-chain claim with rich presentation around it.

What NFTs unlock

NFTs are most useful when they are part of a rule, not just a standalone collectible. A redeemable NFT can act as a receipt: return it to a rule and receive the underlying asset. A role NFT can act as an admin key: the rule checks for it before allowing a special action. A state NFT can hold the latest information for a vault or a payment plan.

That is the pattern to watch. The NFT is not the product. It is the proof that the product's rule was followed. The product might be a ticket, a membership, a loan, a game, or a claim on a real-world asset.

Built for claims you can check

A BCH NFT is a compact, checkable token. It is designed for tickets, receipts, memberships, game items, and information that a rule can read. Large files stay off-chain, and the on-chain claim proves what matters. That is the right split for a payment network.

Used well, an NFT becomes more than a collectible: it is a claim that a rule can check without needing a platform. A ticket, a receipt, or a membership becomes a real, enforceable digital object. The picture was never the point.
